1.2 新增前十大地址归属与关联研究、AIO/ZBT原文证据，以及24h/72h/7天独立跟踪。详细口径、验收与覆盖缺口见 [第二阶段实施记录](Token-Research-2026-10-31.md)。以下市场采集与隔离规则继续保留；旧版验收数字和历史样例对应当时版本。

另有独立 [持续筹码与锁仓观察](Token-Monitoring-2026-10-31.md)，在本页展开查看当前缓存：固定地址余额、按确认区块核对的AIO锁仓参数、过滤转账断点与归属缺口，不回写历史快查结论。

## 使用流程

1. 输入名称、代码或完整合约/Mint，例如 AIO、OlaXBT、ZBT。
2. 对照完整项目名称、CoinGecko ID、链与完整合约，点击正确候选。同名符号全部保留；精确匹配优先，部分匹配仅作线索。不会将 AOI 自动改为 AIO。
3. 选择观察链和候选永续交易对，点击「分析这个代币」。仅符号匹配的交易对尚未获准关联资料；本次 Gate 完整链合约或已有人工完整映射须通过。
4. 阅读当前参与判断、潜力依据、支持/反证/缺失、结构位置、来源及时间。历史报告可从下方打开，也可通过 `?report=<UUID>` 直接查看。

本版本要求目录中存在至少一条链合约/Mint；无合约的原生币、目录缺失项目暂不能完成身份快查。没有本地同代码永续的项目仍可获取项目与支持链的资料，但不能借用其他币的小时线或OI。

## 分析内容与口径

- CoinGecko 按精确 ID 获取项目 USD 价格、流通市值、FDV、现货聚合成交额、供应与 HTTPS 官网入口；使用现有服务配置、Pacer 和可选服务端 API Key。
- Gate 当前币种元数据按完整链地址核对身份。充提/下架信息只对应 Gate，不能据此声称 Binance 下架。资料失败或链合约冲突时，不用同名数据填补。
- 身份关联后按需读取 Binance 永续报价、资金费率、169 根小时K线和289根5m OI数量。小时线、现货聚合成交额、永续报价成交额分别展示，资金费率保留本次原值，不假设所有合约都每8小时结算。
- EMA20/60 与ATR14解释小时结构；支撑/压力仅取右侧两根闭合小时线确认的历史拐点，且位于当前参考价下方/上方。结构失效参考为支撑下0.5ATR，收益风险比未扣费用。缺少压力时不编造目标，不给报告套用模拟账户的10倍杠杆。
- OI 对比同一合约数量，相隔约24h（允许10分钟误差），最新观测不超过11分钟；不同交易对、未来接收时间和价格导致的名义额增加不混用。
- 链上复用同链/完整地址的本地快照；失鲜时通过原有3次预留、50/h、200/day、1000/week的共享额度尝试采集。处于冷却/预算限制时保留缺失，不重置调度、不放宽30GB/月总流量预算。
- Solana 沿用大小写敏感 Mint 与 Owner/Token Account 口径，不能将返回十条账户记录当成全链Owner Top10。提供者标签不自动升级为已验证身份或项目方控盘。

## 判断与完整度

输出「资料不足」「暂不考虑当前买入」「等待确认」「值得继续研究」。它们是可追溯规则生成的初筛，未验证预测收益，不代表已经完成项目尽调。低市值本身不证明低估，FDV/市值差距只提示稀释观察项，不能转换成近期解锁数量。

完整度按十项核验范围计算，当前可采集六类市场输入：身份、报价、项目估值资料、连续小时结构、24h OI、链上及风险字段。地址归属、解锁/公告、产品/团队尽调、盘口深度四类未完成，所以即使市场字段齐全也最多60%。它不是胜率、上涨概率或安全评分。开发初版 `Token-QuickCheck-1` 的六类市场口径报告仍原样保留，历史列表注明旧口径，不与1.1直接比较。

报告生成后两分钟为短线参考期；这只是提醒重新分析，不保证两分钟内价格或风险不变。过期报告显示历史快照，查看不会刷新源时间。相同输入一分钟内复用同版本原报告，最多每小时12份/每日48份新报告；历史查看不联网。

## 独立留档与边界

报告保存到运行目录 `Data/TokenChecks/<UUID>.json`，先写临时文件再原子移动，原始判断、来源与缺失均保留。没有创建新的后台定时探测；没有写入资产映射、自选、链绑定、机会池决策、模拟持仓或真实交易。唯一共享采集写入是已有链上预算/尝试/原始样本，仍由原有单写队列处理。

本轮运行核验：AIO 的 `all-in-one-wallet` 与 `olaxbt` 同名候选分别展示；按用户明确答复选择 `olaxbt`。2026-10-31 09:30:13（上海）报告暂不考虑当前买入，市场报价成交额约177万USDT、小时结构未确认、到历史压力的结构收益风险比不足1.5；本次项目资料来源时间无效，估值保持缺失。ZBT 09:29:24 报告因独立身份来源时间无效降为资料不足，早一轮判断保留在历史中，不作为最新意见。
