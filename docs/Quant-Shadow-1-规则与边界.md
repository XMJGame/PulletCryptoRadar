# Quant-Shadow-1：预先固定的影子规则

本版本仅用于研究，不接管旧模拟盘，不补记历史成交，不承诺日收益。参数定义在 `QuantParameters`，其 JSON、策略定义文本与 Execution-Cost-1 参数共同形成 SHA256。任何策略参数或语义调整须另开版本/摘要，不覆盖已冻结记录。本文件说明待验证假设，不是回测结论。

## 价格与数据

- 337根连续、闭合、当时已收到的1h线；UTC整4h聚合，至少60根闭合4h线。缺口、同小时冲突、未来接收的记录不能填成有效数据。
- 4h EMA20/60及收盘位置决定趋势背景；1h EMA20/60及EMA20的6h斜率同向。EMA采用首值递推，固定337h初始化窗口；ATR为最近14根真实波幅的简单均值。
- 排除非活跃、上市不足337h、报价超过90秒、24h成交额不足1000万USDT及列明的锚定资产。小时ATR/收盘不得超过6%。这是初始研究范围，可能漏掉机会。
- **顺势回踩，多空镜像**：前3根闭合小时与EMA20±0.35ATR带相交；信号线顺势实体、收盘越过前一根高/低并回到EMA20顺势侧；24h成交额中位数量比≥1，延伸不超过1.5ATR。止损使用最近72h中有两根右侧确认的支撑/压力，加0.5ATR缓冲。找不到有效结构则拒绝。
- **放量突破，多空镜像**：信号收盘超过前20根高/低边界0.1ATR；量比≥1.5；收盘位于本根上35%/下35%；距EMA20不超过3ATR。止损是区间转换的失效假设，边界反向0.5ATR且距信号价至少1ATR，不宣称突破边界已成为确认支撑。
- 量比仅使用信号线之前24根的成交额中位数；突破区间排除信号线。所有历史枢轴的右侧确认时间不得晚于信号小时。

## OI与环境

使用同一合约的OI**数量**，不以随币价变化的美元名义价值冒充增仓。只取闭合小时前5分钟及更早、冻结时已收到的点；最新点容许10分钟延迟，1h基点容许5分钟误差，24h基点容许10分钟误差。数量1h变化绝对值>15%或24h>80%为压力拦截；增仓风险倍率1，减仓或缺24h倍率0.5，缺1h则等待。OI不是多空意图识别。

BTC/ETH闭合4h趋势均上行为上行背景、均下行为下行背景，其余分歧。BTC小时ATR>2.5%或ETH>3.5%进入压力状态。需两基准有效及至少20个新鲜成交额合格合约的涨跌广度，否则环境未知。上/下行背景顺向倍率1、反向0.5，分歧0.75；广度强烈反向再降至至多0.5。压力/未知环境不分配新影子风险。

## 计划与组合

- 参考原账户的完整新鲜权益，原持仓及意向的计划风险、保证金和数量占用均计入。最多5笔，同向最多3笔，不同策略不能重复占用同一合约。
- 单笔基础 min(权益×0.4%,4U)，先乘0.5校准倍率，再乘环境、OI、回撤倍率。回撤5%/10%/15%起倍率0.75/0.5/0.25，20%不自动停盘或补钱。
- 总计划风险≤min(权益×2%,20U)；同向及高相关组合各≤min(权益×1.2%,12U)。对齐最近72h收益，至少60对有效值，|Pearson|≥0.75视为相关；未知也按相关计入，不将多空风险相抵。
- 单笔保证金≤100U，杠杆从5到1依次尝试。按真实合约数量步长向下取整，使用当时新鲜盘口VWAP、手续费及残余滑点假设，保留资金费和0.1%名义价值跳空压力预算。
- 最新公布费率绝对值>0.3%或付费方向>0.1%拒绝；高绝对费率降低倍率。未来资金费不是已知现金流：以当前付费方向费率×1.5及72h预留，不提前确认收款。调整周期证据缺失按1h保守估算，不假定所有币8h。
- 估算强平位置采用**1%维持保证金率假设**，扣除手续费和资金费压力后要求止损比强平估值提前至少1ATR。不掌握实际维持保证金档位、跳空和执行延迟，不能保证不爆仓或不穿仓。
- 实时报价离冻结信号收盘价>0.75ATR不追。首目标选≥2R的最近已确认历史结构，否则2R投影；次目标再远至少1R，否则4R或更远投影。首目标扣成本和资金费压力后的收益需≥1.2倍总计划风险。投影不标成历史压力位。
- 30%/30%/40%尾仓、3入场ATR跟踪和最长72h是后续回放/退出模块的待验证方案，本阶段只给目标与风险计划，尚不执行退出或收益曲线。

## 前瞻和存档

每个参数摘要保存独立批次起点。仅起点之后的整点、前10分钟内冻结前瞻判断。前9分钟允许等待基线，之后资料不足原样保存。候选有效120秒，前瞻计划还须等到价格、标记价及盘口的源时间和收到时间严格晚于冻结时刻；估算方案仍不等于成交。

固定每小时最多60个深度候选，复用已有采集池；BTC/ETH及原持仓另作环境/组合核对。只给最多3个热点增加受预算约束的报价/盘口采样。应用的30GB月度预算保持不变，接口GET不触发外部请求。

存档位于 `Data/QuantShadow/<参数SHA256>/`：`cohort.json`、冻结 `Forward/<小时>/universe.json`、每币4项不可变判断、内容寻址压缩原始输入、前瞻成本/组合评估及最新只读快照。当前预览与前瞻明确分开；未触发的预览仅保留计算摘要，不能冒充完整前瞻档案。所有已冻结前瞻判断和价格触发预览保留原始输入。

OI字段、资金费调整周期与交易规则的接口语义参考 [Binance USDⓈ-M官方行情接口文档](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data)。本版本仍需历史回放、时间外验证和成本压力测试，之后才考虑迁移新开仓。
