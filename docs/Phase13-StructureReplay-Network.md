# Phase 13：结构策略离线诊断与省流控制

2026-10-29。两套策略初版、支持/压力与波动缓冲、数量风险约束、分批退出和尾仓跟踪已实现于离线研究引擎 scripts/replay_strategy_research.py。输入为完整预选月份的SHA256校验档案，不是峰值附近裁剪的展示曲线；不会联网下载或写入在线Paper账本。

Rules-R1.json在首次运行前冻结，未根据回放收益调参。A为收敛区间上部量能启动的提前观察代理，B为24h涨幅＋放量突破的候选代理；均另设OI确认版以及两倍费用/滑点情景，三个日期区间共24组独立组合诊断。17个合约均可进入组合，含BTC/ETH，每组初始1000 USDT，不能相加。每笔保证金最多100、10倍逐仓、最多两笔、计划风险最多10且不超过权益1%，另有日损30和时段权益回撤15%的新仓熔断。

支撑使用右侧两根已闭合K线确认的摆动低点，加0.5 ATR止损缓冲；合理止损与估算强平线安全空间冲突则跳过。止盈优先用当时可确认压力，无合适压力时用明确标记的风险倍数投影，各减原始数量30%，剩余40%按入场ATR的3倍跟踪保护，下一小时才生效。最多持有168小时。信号小时不成交；下一小时开盘加不利滑点。小时内无法确定先后，按强平压力、止损、止盈的保守顺序处理，不能称真实盘中路径。

资金费按实际记录的时点及符号计收，价格使用当小时标记开盘价或成交开盘代理。入场时缺少24h内历史结算记录则不开仓；持仓遇路径缺口，在下一可见开盘压力退出，不能回看补卖在缺口前收盘。资金费结算价缺失时使用最后可见收盘代理，并留计数。持仓末期的模型平仓、标记价代理、资金费价格代理及隔离清算调整均可核对。双精度研究金额核对至1e-6 USDT，未取代在线decimal账本。

重要边界：所有样本已被研究，没有未参与研究的留出；按早/中/后段分割只是诊断。OI本来按事后事件选段采集，其缺失模式有选择偏差；五分钟可见延迟也是研究假设，没有历史真实到达时间。地址、钱包、消息、订单簿、精确步长与真实维持保证金阶梯缺失。B缺少当时全市场可交易全集与排行榜。因此自动开仓继续关闭，线上本金1000、零成交；不能把正收益的少数样本认定为策略已通过验证。

结果：docs/research/backtest/策略回放诊断-R1.md、Summary.json、Rules-R1.json及24份逐笔账本/权益文件。UI入口 /strategy-replay，可按时段/变体读取本地逐笔计划与退出原因。

## 省流模式

Network.EconomyMode默认true。关闭全市场持续WebSocket，完整市场ticker约60秒一次，指定7个重点标的ticker/premiumIndex约20秒补充；历史补齐只取优先/活跃20个，历史目标1m240/5m288/15m192根，OI仅20个、深度最多10个、每次35条。历史实际仍每5分钟检查/补缺，不重复下载整段。其他标的/指标保持真实缺失或失鲜；未放宽原来的30秒价格与资金费新鲜度门槛，所以本模式不具有全市场秒级覆盖。

Gate/Coinbase参考轮询默认600秒、候选5个；CoinGecko默认60分钟；资金流轮询600秒、请求预算每小时160/每日1000，保留确认数和重组停机保护。原有本地缓存、游标与冷却未清空。

全部由HttpClientFactory创建的数据源客户端经过统一计量与预算handler，请求gzip压缩，在计数后解压；成功、错误响应和部分失败读取都计入。完整模式WS应用负载也计入。默认150,000,000字节/上海自然日、5,000,000,000字节/上海自然月，记录原子落盘，重启不清零。到达上限中断当前读取、暂停新请求；数据自然失鲜，不视为实时通过。原始计数持久化到运行Data目录 network-usage.json，不能手工删除以绕过限制。

这是本程序的正文负载预算，未含HTTP头、TLS/TCP、VPN封装、系统预取/缓冲与在途额外数据，不是运营商精确流量封顶；其他软件、Codex通信以及独立历史下载脚本不计。压缩与预算是独立机制，不承诺固定月流量或一定能全天采集。研究回放本轮网络请求为0，未额外下载历史档案。

接口 /api/network，页面 /network；首页展示省流/预算暂停状态，导航仍四项。没有修改用户系统路由、VPN开关、Clash配置或其他软件网络行为。

## VPN与直连测试

在VPN仍开启的情况下，以curl --noproxy '*'对Binance时间、Gate时间、Coinbase时间与公开档案校验文件做小请求，均HTTP200。这些不是关闭VPN后的直连证明。检测到clash-verge / verge-mihomo及Meta默认路由，TUN可能仍接管请求。UseSystemProxy=false仅关闭本程序HTTP显式系统代理，不能绕过系统路由。实际采集的Coinbase来源是api.exchange.coinbase.com，v2时间接口探测不能替代对该来源的验证。

一次全市场ticker压缩正文实测66,672字节，仅作当时样本；按60秒间隔机械外推约96 MB/日，仅ticker，非整个程序或VPN账单预测。重点行情、历史、衍生品、TLS/VPN开销另计。以 /network累计负载和VPN账单为准。

若要不消耗VPN套餐，可在Clash规则模式中，先逐个验证关闭VPN仍能访问的源，再设置DIRECT。示例见 Network-Direct-Rules.example.yaml。只合并验证通过的规则并置于兜底MATCH规则前，不覆盖整份订阅配置；连不上就保留缺失/仅对该域名代理，不用Coinbase现货冒充永续合约OI。本轮未自动改动这些规则。

来源：[.NET UseProxy](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpclienthandler.useproxy?view=net-10.0)、[Binance Market Streams](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/ws-streams/market)、[Binance公开档案格式与校验](https://github.com/binance/binance-public-data)。网络可达性只代表本次实测。
