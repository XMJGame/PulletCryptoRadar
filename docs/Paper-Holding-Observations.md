# 模拟持仓检查与过程留档

2026-10-29。风险执行约每5秒一次，重点价格/标记价在省流模式下约20秒补充，OI轮询约300秒；风险循环不会创造比数据源更新更快的新行情。开仓分析使用闭合1h线，每个小时的前10分钟内完成，下一次21:00是新小时分析点，不是已有持仓要等到21:00才止损或退出。

持仓执行检查：价格/标记价与本机接收时间是否有效、结构止损或尾仓跟踪线是否越过、两级目标是否达到、分批减仓状态、最多168h超时、估算逐仓强平、保证金/费用/资金费假设、其他仓位是否失鲜及余额/组合风险能否继续新开仓。多空分别计算。OI、资金费报价和可用链上信息会留档，但目前并非所有辅助指标都会自动触发卖出/回补；主要退出条件仍为价格结构、目标/跟踪、超时和估算强平。

新增PaperHoldingSnapshot表（业务库SchemaVersion=12），约每分钟存一份当时持仓上下文；开仓、减仓、平仓额外保存，不受一分钟节流。和账户状态/结算同事务提交，带账户Revision、PositionId及策略版本，失败整批回滚。查询只读本地，不增加任何外部HTTP/WS请求。没有持仓时不产生假记录，补充功能发布前没有采样的时段也不回填。

每条保存：当时持仓方向、数量、初始/当前保证金、开仓费及未分摊资金费假设、初始与当前止损、两级目标、分批标志、追踪有利价格、原始分析证据；当时MarketView完整可用字段，包括成交价/标记价、24h涨跌及成交额、OI数量/名义值/变化、Taker、多空账户比、资金费报价、价格统计、市值/身份与链上特征。所有指标保留自己的来源时间与状态；没有地址/钱包证据不视为安全。

价格或标记价失鲜时仍记录原始上下文，但MarkPnl/AccountEquity为Unknown，不把历史报价重新标成当前。平仓快照说明“数量为退出前”，本次结算腿另附；减仓快照为减仓后数量。开仓前的判断以PaperIntent/PaperAudit分析记录为准，不能把持仓快照拿来倒推当时未可见的信息。

这不是每5秒或逐笔盘口档案，无法证明两次采样之间发生的最高/最低价、止损目标先后或真实可成交深度。20%本金亏损仅提醒复盘、继续实验的用户要求不变。数据源失鲜或网络预算暂停时无法保证及时风险退出。

入口：每日复盘 → 持仓过程留档。显示最近200条，可选单笔持仓并按时间游标翻看更早记录；默认API最多1000条，完整记录继续保存在本地数据库。/api/paper/holding-history支持positionId、limit、before，翻页必须先选定单笔持仓，避免多仓同时间分页遗漏。平仓后留档不删除。
