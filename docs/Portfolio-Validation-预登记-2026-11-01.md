# Quant-Portfolio-Validation-1 预登记

本轮固定原策略和成本模型，不做参数寻优。使用保存的完整准入资料重算Intent/Admission（包括非成交结果），独立核对新仓的数量、杠杆、止损、现金/其他意向费用预留、五个持仓及意向额度、500U原保证金、单笔/总/同向/相关风险。相关性缺失按原规则计入相关组，旧仓也占用额度。其他阶段分别列为未重算，不用通过率掩盖缺资料。

冻结原账户、全成交/资金费及当时本机市场/盘口/规则/资金费缓存，在独立内存中调用原连续执行引擎一轮，重跑及反序列化后输出应一致；不调用IPaperPersistence、不追改原盘、不取之后行情。它是单轮工程检查，不是历史连续账户收益回测。

固定边界案例：原保存复核、四占用后第五笔、五占用拦第六笔、意向占用、同向上限、同币、总风险用尽、相关未知风险用尽、四笔大保证金、低现金、其他意向预留现金、缺权益/标记价/盘口/资金费，以及压力环境、回撤不加风险。案例仅修改隔离准入输入，明确为合成约束测试，不冒充五笔实际持仓、可交易组合或盈利样本。种子固定选当日最新Filled/Admission资料，缺失/不能独立复算时保持未知，不挑其他更有利种子。

保存内容寻址的原复核/信号资料，以及不可变副本输入、报告和哈希。全部复核参与计数，页面最多显示100条并标明；缺旧入场留档、当前不足五笔实际仓、没有连续完整市场历史及真实撮合/保证金档位的证据继续列Unknown。默认只读展示已有结果，用户操作或本次验收显式生成；不新增高频采集或后台自动交易。
