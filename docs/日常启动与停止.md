# 日常启动与停止

在 G:\XuMingJun\2026\Pullet\PulletCryptoRadar 文件夹中：

1. 双击“启动服务器.cmd”。服务器控制台显示后，浏览器会打开 http://localhost:5218。
2. 采集期间保持服务器窗口开启，可以最小化。关闭浏览器不影响采集。
3. 要停止时关闭服务器窗口，或双击“停止服务器.cmd”。停止不删除数据库。再启动继续读取保存记录。

真正运行的是 artifacts\win-x64\PulletCryptoRadar.exe，启动脚本只是助手。当前为本机普通进程，没有安装成Windows服务，没有开机自启动，也没有独立桌面主界面/托盘图标。任务栏显示的是服务器控制台窗口或Windows终端，标题为 PulletCryptoRadar Server - http://localhost:5218；网页界面在浏览器里。窗口的任务栏分组和图标取决于Windows控制台宿主。

已在运行时再次启动仅打开网页，不会重复启动；也不会改变已有窗口的隐藏/显示方式。如以前以隐藏方式启动，请先停止再启动。普通启动现在默认显示窗口。确需后台运行可在PowerShell执行 .\Start.ps1 -Background；只启动而不打开网页可执行 .\Start.ps1 -NoBrowser。

“停止服务器.cmd”只匹配当前项目 artifacts\win-x64\PulletCryptoRadar.exe 的绝对路径，不按端口任意杀进程。停止采用结束进程；SQLite已提交事务保留，未提交事务由数据库恢复，正在采集的一轮可能未保存。下次启动不会补造这段快照。

采集与前瞻标签需要电脑开机、未休眠、程序运行且网络数据有效。界面有数据不足/失鲜/观察记录停更提示；网络预算耗尽也会导致数据失鲜。每天打开“每日复盘”或 http://localhost:5218/forward 查看，不需要每天手工运行回放脚本。本轮不会发送真实委托。

启动失败时窗口会保留错误信息。先检查端口5218是否被占用，以及 artifacts\win-x64\Logs 中的日志。不要删除Data目录来排查；其中包含账户、冻结观察记录与网络用量。
