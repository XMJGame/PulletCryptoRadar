# 日常启动与停止

在 G:\XuMingJun\2026\Pullet\PulletCryptoRadar 文件夹中：

1. 双击“启动服务器.cmd”。显示独立的服务器观察窗口，浏览器打开 http://localhost:5218。
2. 观察窗口可以最小化，也可以关闭；关闭窗口、按Q或Ctrl+C只结束观察，后台采集继续。关闭浏览器也不影响采集。
3. 要停止服务器，双击“停止服务器.cmd”，或在观察窗口按S，等待正常排空写入。停止不删除数据库。再启动继续读取保存记录。

真正采集的程序是 artifacts\win-x64\PulletCryptoRadar.exe。默认启动脚本通过当前用户的按需计划任务运行 artifacts\supervisor\PulletCryptoRadar.Supervisor.exe，再由守护无窗口启动服务器。观察窗口由scripts\Server-Window.ps1独立显示状态和日志，关闭不会结束守护或服务器。这些仍是普通本机进程，没有安装成Windows服务。任务没有开机、登录或定时触发器，电脑重启后仍需双击启动；没有托盘图标。网页界面在浏览器里。

本工作区任务名为 `PulletCryptoRadar-9D49394A64D54147AB7A`，当前用户交互令牌、普通权限，无密码存储。显式停止会先写停止标记，禁止守护再拉起，然后请求服务器正常排空写入；不要用结束任务/进程代替日常停止。如果确需移除守护任务，先正常停止，再运行 `Unregister-ScheduledTask -TaskName 'PulletCryptoRadar-9D49394A64D54147AB7A' -Confirm:$false`；重新双击启动会重建按需任务。临时无守护启动可用 `.\Start.ps1 -Direct -NoBrowser`，不享有自动恢复。

守护每10秒检查本机健康；进程异常消失且无正常Stopped记录时，按15/30/60秒退避恢复，10分钟最多3次自动重启，第四次异常停止恢复并记录保护状态。正常停止不重启；进程存在但健康异常时只提示，不强杀或再开一个。守护自身失败、电脑关机/休眠或用户注销也可能停止采集，不能承诺全天连续运行。观察窗口不承担守护职责，选中文字不会阻塞服务器日志。

已在运行时再次启动不会重复启动服务器；观察窗口已关闭时会重新打开观察。普通启动默认显示观察窗口。无需观察窗口可执行 .\Start.ps1 -Background；只启动而不打开网页可执行 .\Start.ps1 -NoBrowser。若观察窗口已经打开，Background不会强行关闭它。

临时使用Direct模式时仍是旧式服务器控制台：关闭它或Ctrl+C会停止Direct服务器，不享有独立守护恢复。程序会关闭自身控制台的鼠标快速选择；旧版本若因选择文字阻塞，可先按Esc，再正常停止。默认观察窗口模式无需保持窗口开启。

“停止服务器.cmd”只匹配当前项目 artifacts\win-x64\PulletCryptoRadar.exe 的绝对路径，通过当前用户的本地命名管道请求正常退出，先停止采集，再排空已经接收的数据库写入；默认最多等待60秒。请求失败或超时会明确报错，不会自动强杀。已接收写入若自身校验或存储失败仍会记录错误；尚未采集完成、未入队的请求不保证保存，下次启动不会补造快照。不要用任务管理器结束进程作为日常停止方式。

仅在程序无响应，或旧版本不支持正常停止时，可在项目目录执行 `.\Stop.ps1 -Force`，明确强制结束；已提交事务保留，未完成工作可能丢失。日常使用停止脚本或观察窗口S；观察窗口Ctrl+C不会停止后台服务器。

更新程序时，依次执行 `.\Stop.ps1`、`pwsh -File .\scripts\Publish.ps1`、`.\Start.ps1`。发布脚本在目标服务器运行时拒绝覆盖文件；启动和发布也共享目录锁，避免同时操作。另有数据目录独占锁防止两个服务器同时管理同一模拟账户。不要删除锁文件或Data目录来绕过拦截。

采集与前瞻标签需要电脑开机、未休眠、程序运行且网络数据有效。界面有数据不足/失鲜/观察记录停更提示；网络预算耗尽也会导致数据失鲜。每天打开“每日复盘”或 http://localhost:5218/forward 查看，不需要每天手工运行回放脚本。本轮不会发送真实委托。

启动失败时窗口会保留错误信息。先检查端口5218是否被占用，以及 artifacts\win-x64\Logs 中的日志。不要删除Data目录来排查；其中包含账户、冻结观察记录与网络用量。
