## 两条研究路线

### 提前埋伏

研究 LAB、MYX、BTW 等完整周期中的横盘/收敛、成交变化、OI与价格组合、可核对供给及钱包证据。每个候选特征必须注明最早可见时间，不用后来的涨幅、当前持币分布或当前市值倒填过去。要加入相近波动、成交、上市年龄却未上涨、下跌或退市的对照组；当前种子样本不具代表性，不能据此宣称已找到稳定规律。

目标输出：处于什么阶段、哪些前置证据已满足、还有什么缺失、何时等待确认、何时失效。提前观察不等于立即开仓；没有可验证支撑和合理风险空间时不产生执行计划。

### 涨幅榜机会

只使用当时可见排名及市场信息，区分首次启动、回踩延续、二次拉升、过热和派发。催化原因分别标示可靠消息、量价/OI现象、链上事实及未知；相关性不写成原因或内幕结论。新闻要保留发布时间和事件时间，不能使用事后报道解释当时可交易性。

目标输出：等回踩、等确认、仅观察、跳过，或有完整证据的模拟执行计划。单独统计追涨后的止损、回撤、延续收益和交易成本，不能将排行榜涨幅当作策略收益。

## 结构决定价格，风险决定数量

研究计划中的止损须来自在当时已经确认的历史支撑/摆动低点和波动缓冲。确认摆动点时，右侧确认K线也必须已经闭合。不能直接采用整段历史最低点，也不能为了提高收益率回看后选择最有利支撑。

建议表达为：

数量上限 = min(100 USDT ×10 ÷ 入场价, 单笔允许损失 ÷ (入场价−结构止损价+单位预计成本))。

保证金 = 数量×入场价÷10；100只是上限。单笔允许损失、ATR缓冲和结构确认参数仍须历史及样本外验证，不在本轮宣称已经确定。若合理止损位超出10倍逐仓估算强平线的安全空间，则跳过，不强行缩短止损。

止盈研究采用可验证压力区间分批减仓，并保留趋势尾仓：例如第一压力区释放一部分风险，下一压力区再释放，剩余按更高周期支撑/波动跟踪退出。减仓比例、何时上移保护、尾仓比例须比较不同大行情及失败样本后再版本化，不能仅因怕错过百倍而无限持仓。止损可能滑点、跳空；逐仓与模型返还金额下限不是对真实交易不穿仓的保证。

## 初始数据与限制

原始数据位于 docs/research。LAB Gate 381条原始日线，剔除当日未闭合后380条；BTW Gate 148/147；APR Gate 372/371。MYX Gate读取失败，改用Binance原生MYXUSDT日线499/498。各交易所分开，不拼成同一市场的连续基线。

scripts/Analyze-ResearchCandles.ps1 验证正数OHLC、非负成交量、重复时间及所用窗口连续性，生成 CaseInventory.json。每个交易对选取三个不重叠的事后7日大涨区间，仅作为案例索引；这些未来最高/最低价格是标签，不是已知特征、可执行收益或胜率。当时已知字段为20日范围与当前已闭合日量/此前20日量中位数。

日线不含分钟级路径，不能确定止损/分批止盈先后，不能假设能在最高价卖出。历史OI、资金费、盘口、链上身份及消息覆盖仍需补齐；缺失必须单独记录。当前尚缺系统性的失败/退市对照、训练/验证/留出分离及前瞻样本。

依据：[Gate API Candlesticks](https://www.gate.com/docs/developers/apiv4/en/#futures-candlesticks)、[Binance Kline API](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Kline-Candlestick-Data)。API原始响应保存了交易对、来源及抓取记录。任何模拟都需明示价格和成本假设，不能冒充真实业绩，参见 [CFTC关于假设交易结果的说明](https://www.cftc.gov/LearnAndProtect/AdvisoriesAndArticles/fraudadv_tradingsystem.html)。

## 虚拟账本基础

PaperAccount、PaperTrade、PaperAudit写入业务库，SchemaVersion=11。单写入队列、版本CAS、成交与账户同事务提交，恢复时不重置本金。账本单元测试涵盖下一报价成交、未来/过期数据拒绝、保证金与手续费、资金费假设、跳空、隔离清算调整、暂停后风险退出、去重及原子恢复。

早期原型曾使用固定1.5%止损、3%止盈，用户随后明确要求结构分析与分批退出。这些原型参数未作为正式交易策略发布执行，仅用于账本数学测试。新账户Enabled=false、ResearchValidated=false，执行器有双重门槛；POST /api/paper/resume 当前明确返回409，无法用按钮启用未验证策略。无任何真实交易API、密钥或委托功能。

账本暂保留手续费每边0.05%、滑点每边0.05%、每8h0.01%保守资金费和0.5%维持保证金率作为未验证数学假设，绝非交易所真实规则。清算/隔离模型调整另记SettlementAdjustment，以使Gross−Fees−Funding+Adjustment=Net，可用余额与结算核对。逐笔盘口、数量步长、盘中路径均未完整建模，不能将该原型称为可实盘策略。

## 接下来的验收顺序

1. 扩充同交易所分钟/小时历史、完整周期、失败及退市对照，标明每项历史字段覆盖。
2. 分别建立两条策略的可证伪假设；只使用决策时可见信息，冻结参数和数据切分。
3. 实现结构支撑/压力与风险仓位计划；按保守日内触发顺序、实际或明确缺失的资金费验证分批退出/尾仓，不能用最高价假成交。
4. 比较扣成本收益、回撤、尾部损失、盈亏比、持有时间、误报及漏报；按不同时期做样本外检验。
5. 达到研究验收后另发策略版本，再开放前瞻模拟执行。每天复盘，但不因一两笔盈亏自动调参，不改写旧账。
